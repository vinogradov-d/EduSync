# Тестирование проекта EduSync

## Проверка главной страницы
- Главная страница открывается в браузере.
- Основные разделы отображаются корректно.
- Навигация между разделами работает.

## Проверка поиска
- Поиск по учебным материалам выполняется.
- Результаты поиска отображаются корректно.
- При отсутствии результатов показывается соответствующее сообщение.

## Проверка формы регистрации
- Обязательные поля проверяются.
- При некорректном вводе отображаются сообщения об ошибках.
- При корректном заполнении форма обрабатывается.

## Проверка адаптивности
- Интерфейс проверен на широком экране.
- Интерфейс проверен на мобильном размере экрана.

## Результат
Основные элементы интерфейса и функции проекта проверены.
