# История изменений EduSync

Все заметные изменения проекта фиксируются в этом файле.

## [1.1.0] — обновление интерфейса

- Переработана главная страница в соответствии с визуальными материалами EduSync.
- Добавлена библиотека учебных материалов.
- Добавлена галерея видео и заданий.
- Добавлен раздел образовательных марафонов.
- Добавлена форма регистрации с проверкой полей.
- Добавлен раздел уведомлений и действие отметки прочтения.
- Реализована адаптивная навигация для мобильных экранов.
- Обновлена документация проекта.

## [1.0.0] — исходная версия

- Создана базовая структура HTML, CSS и JavaScript.
- Добавлены основные разделы образовательной платформы.
- Настроен поиск по каталогу курсов.
