# EduSync — образовательная платформа

## О проекте

EduSync — демонстрационная образовательная платформа, предназначенная для организации учебного процесса. Проект объединяет каталог курсов, учебные материалы и возможность отслеживания прогресса обучающихся.

Проект выполняется в рамках учебной практики УП.06 по профессиональному модулю ПМ.06 «Сопровождение информационных систем».

## Цель проекта

Создать и продемонстрировать интерфейс образовательной платформы, который помогает пользователям находить учебные курсы, получать доступ к материалам и контролировать результаты обучения.

## Основные возможности

- просмотр каталога образовательных курсов;
- поиск курсов по названию;
- демонстрация учебных материалов;
- отображение прогресса обучения;
- адаптивный интерфейс для компьютеров и мобильных устройств.

## Используемые технологии

- HTML5 — структура веб-страницы;
- CSS3 — оформление и адаптивный дизайн;
- JavaScript — интерактивные элементы и поиск курсов;
- Git — контроль версий проекта;
- GitHub — хранение исходных файлов и истории изменений.
