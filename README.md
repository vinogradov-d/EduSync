# EduSync

EduSync — веб-проект образовательной платформы, предназначенной для удобного представления учебной информации и образовательных материалов.

## О проекте

Проект представляет собой адаптивный сайт с несколькими тематическими разделами. Его цель — объединить учебные материалы, видео, задания и информацию об образовательных мероприятиях в одном интерфейсе.

## Основные разделы

- **Главная страница** — знакомство с платформой EduSync.
- **Учебные материалы** — карточки с образовательными материалами по различным дисциплинам.
- **Галерея** — визуальное представление учебного контента.
- **Образовательные марафоны** — информация о доступных образовательных мероприятиях.
- **Регистрация** — демонстрационная форма с проверкой заполнения полей.
- **Уведомления** — раздел для отображения уведомлений и взаимодействия с ними.

## Используемые технологии

- HTML5 — структура веб-страницы.
- CSS3 — оформление и адаптация интерфейса под разные размеры экранов.
- JavaScript — интерактивные элементы сайта.
- Git — контроль версий проекта.
- GitHub — хранение исходного кода проекта.

## Запуск проекта

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/vinogradov-d/EduSync.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd EduSync
   ```

3. Открыть файл `index.html` в браузере.

Для просмотра проекта также можно использовать расширение Live Server в Visual Studio Code.

## Примечание

Текущая версия EduSync является демонстрационным веб-проектом. Некоторые элементы интерфейса предназначены для демонстрации внешнего вида и взаимодействия. Для полноценной регистрации пользователей и сохранения данных потребуется дополнительная серверная часть.
